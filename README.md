# Guías gratis · Lumière Autómata

Las guías y prompts que se regalan en los reels de [@lumiereautomata](https://www.instagram.com/lumiereautomata/). Se publican en GitHub Pages: https://arqjorgeml1204.github.io/lumiere-guias/

Cada guía es `fuentes/<slug>.md` más su entrada en `guias.json`. Para construir: `npm install` y `node herramientas/construir.mjs`.
